1. Purpose & Objective
Sonu’s resume is intentionally narrow — tailored to Data Analyst / BI
roles. The portfolio website exists to show the full range behind that
resume: analytics depth, plus real engineering, automation, and
application-development work that the resume can’t ﬁt.
The site must never read as “just a Data Analyst site.” It should
read as a Data & Technology professional who happens to be
strongest in analytics, but who ships real systems end-to-end —
dashboards, pipelines, apps, and automation.
Core question the site answers: > “What can this person actually
build?” — not just “what jobs has this person held?”

8. Content Rule: Portfolio ≠ Resume
The site must never just restate the resume. For every resume
bullet used, the site should link to or expand into: the actual
dashboard/screenshot, the business problem, the technical approach,
and the outcome — evidence, not just claims.
9. Non-Functional / Architecture
Requirements
1. Expandability is a hard requirement. Adding a new project,
certiﬁcation, or experience entry must not require touching layout
code — data-driven cards (JSON/CMS-backed) per project.
2. Category taxonomy is ﬁxed but extensible — new categories
(e.g. “AI/ML,” “Enterprise Systems”) can be added to the ﬁlter bar
without redesign.
3. No dead-end pages — every project card resolves to a real
destination (repo, live demo, or case-study write-up), never a
placeholder.
4. Enterprise-credible visual bar — professional enough for
enterprise recruiters despite the vivid palette; avoid template-
generic Lorem Ipsum polish, avoid looking exclusively like a
designer/frontend portfolio.
5. Responsive — capability rows and ﬁlter grid must collapse cleanly
to mobile (stacked cards, single-column pill wrap).
10. Explicit Non-Goals (v1)
Not a multi-page CMS-driven blog (structure should allow it later,
not build it now).
Not attempting to claim “expert” level in exposure-only
technologies (Snowﬂake, Azure) — these stay labeled as Technical
Exposure.
Not a generic template reskin — reference sites are for pattern
and palette inspiration only, not literal reuse of their copy or
stock imagery.
